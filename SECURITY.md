# Security

Report a bypass (a missed path, a kernel where the hook does not run) or a
bug that is not public yet
[privately](https://github.com/conformal-co/shirudo-shields/security/advisories/new),
with the CVE or tracker id and the embargo date. Embargoed shields are
developed in the advisory's private fork and merged when the embargo lifts.

A shield that breaks legitimate use or does not load is a public issue.
Meanwhile set `mode=audit` or exempt the affected UID.

Bugs in Shirudo go to the Shirudo project; bugs in the stock-kernel port
and the installer to
[conformal-co/shirudo-today](https://github.com/conformal-co/shirudo-today).
